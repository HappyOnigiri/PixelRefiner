# Pixel Refiner 1.0.0 リリースノート

## 新 Auto パイプラインの正式運用

新しい入力分類、グリッド候補、通常画像向け Convert、低信頼度時の候補選択を
組み合わせた Auto パイプラインを既定の処理経路にしました。等倍画像や判定困難な
画像は原寸を維持し、通常画像はConvert、信頼できるグリッドを持つ画像はRefineへ
自動的に振り分けます。

Pull Request の品質ワークフローでは、同じ fixture に対するベースブランチと
変更後の出力に加え、既定AutoとLegacy互換設定を比較します。処理経路、出力サイズ、
再現性、破局的失敗、主要品質指標の差をGitHub Actionsのサマリーへ掲載します。

## ロールバック

問題が見つかった場合は、リリースを直前の安定版へ戻してください。互換テストでは
`LEGACY_PROCESS_OPTIONS_V1`を使って従来出力を再現できるため、原因調査と修正版の
比較に利用できます。
