# Pixel Refiner 1.0.0 リリースノート

## 段階導入中の新 Auto パイプライン

新しい入力分類、グリッド候補、通常画像向け Convert、低信頼度時の候補選択を
組み合わせた Auto パイプラインを開発者向け feature flag として追加しました。
既定では従来パイプラインを維持し、`?pipeline=next` を指定した場合だけ新しい
Auto ルーティングを使います。

Pull Request の品質ワークフローでは、同じ fixture に対するベースブランチと
変更後の出力を比較し、品質指標の要約を GitHub Actions に掲載します。新 Auto の
既定値化は、破局的失敗率、サイズ正解率、再現性、背景マスク、小成分保持率、
処理時間のゲートを満たした後に行います。

## ロールバック

問題が見つかった場合は `?pipeline=legacy` で従来パイプラインへ戻せます。
保存済みの選択を削除して既定値へ戻す場合は、ブラウザーコンソールで
`localStorage.removeItem("pixel-refiner-pipeline")` を実行します。
